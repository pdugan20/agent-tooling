What these mean

Two kinds of building blocks

Skill

A reusable set of instructions for one kind of work—for example, reviewing SwiftUI or using strict TDD.

Plugin

An add-on installed in Codex or Claude. It can contain several skills or connect to a product such as Figma or Firebase.

When a skill runs

“Can start automatically” means the agent may use it when it fits. “Only when asked” means you must request it directly.

Patrick Delivery is our own plugin. It packages six production workflows; it is not a separate app or service.
